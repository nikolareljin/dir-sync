Get started

Create your first safe backup

  1. Open the tray menu and choose Add new action.
  2. Choose an existing source folder and destination folder. The browser remembers its last location and begins at your home folder when no location is available.
  3. Select Run manually or a schedule.
  4. Leave Preview only enabled, run the action, and inspect the result.
  5. Uncheck Preview only only when the proposed changes are correct.

Install from source

git clone https://github.com/nikolareljin/dir-sync.git
cd dir-sync
python -m venv .venv
source .venv/bin/activate
pip install -e .[dev]
./start

Use the release assets when you prefer a packaged build for your platform.
