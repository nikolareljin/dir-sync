Direction matters

Both current modes copy from Source to Destination.

ModeChanges copiedDestination-only files
BackupChanged source files overwrite matching destination files.Kept.
MirrorChanged source files overwrite matching destination files.Deleted so destination exactly matches source.
Mirror is destructive. The editor asks for confirmation because it removes destination-only files. Use Preview only before a real mirror run.

What is not available yet

Neither mode is two-way. A newer file at the destination is not copied back to the source. Compression and timestamped archive backups are also not implemented in this release.

Filters

Add include or exclude glob patterns when an action should operate on only part of a directory. Test filters with Preview only before running for real.
